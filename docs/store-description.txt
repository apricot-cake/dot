=== SUMMARY (max 132 chars) ===

Save web posts and artwork to your PC with images, text, creator, and source URL, then search them. Nothing goes to our servers.

=== DETAILED DESCRIPTION ===

“Where did I save that post?” Spend less time searching with a library of your own.

dot brings posts and artwork from X, Bluesky, and pixiv into a library you can return to. Search what you have saved in the dot app for Windows, and organize it with tags and folders.

Install the dot app for Windows first, then add this extension. On supported sites, hover over a post and press its save button. To save a single image or video, right-click it and choose dot.
