# 作品とキャラ

詳細パネル（インスペクター）の「タグ」には、作品・キャラの選択欄と「その他のタグ」を表示します。作品は単一選択、キャラは複数選択です。「別の作品」で複数作品にも対応します。検索で候補がなければ作成できます。

作品だけ、キャラだけでも付けられます。作品が未選択なら全キャラを検索でき、所属作品があるキャラを選ぶと作品も付きます。作品に属さないキャラも登録できます。

キャラから自動で付いた作品は、最後のキャラを外すと外れます。手動で選んだ作品は残ります。作品の変更・解除では、その作品のキャラも外れます。「元に戻す」で直前の付与状態へ戻せます。

既存タグは「タグを分類」で作品・キャラへ変更します。タグの ID と、既存の投稿に付けた状態は保ちます。キャラの所属作品は任意です。同名キャラは所属作品で区別します。

## 保存

データベースの構造を表すスキーマのバージョン 50 では、`tags.category` に通常タグ・作品・キャラの区別、`tags.workId` に所属作品を保存します。`post_tags.implied` は作品の自動付与を表します。スキーマ49は起動時に50へ更新し、既存タグを通常タグとして維持します。

バックアップ用の ZIP には、作品・キャラの一覧と、各投稿に付けた作品・キャラを保存します。名前と所属作品を組み合わせて記録し、別のライブラリへ取り込むときは取り込み先の ID に対応付けます。ゴミ箱からの復元でも所属作品と手動・自動の区別を保持します。
