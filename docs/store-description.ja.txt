=== 要約（最大132文字） ===

ウェブで見つけた投稿や作品を、画像・本文・投稿者・元 URL とともに PC へ保存します。保存後はライブラリで検索できます。dot のサーバーへは送信しません。

=== 詳細説明 ===

「あの投稿、どこに保存したっけ」。そんな探しものを減らしてみませんか。

dot なら、X、Bluesky、pixiv の投稿や作品を、あとから探せるライブラリにまとめられます。保存した内容は Windows 版 dot アプリで検索でき、タグやフォルダで整理できます。

先に Windows 版 dot アプリをインストールし、この拡張機能を追加してください。対応サイトでは投稿にマウスを重ねて保存ボタンを押します。画像や動画を1つだけ保存するときは、右クリックから dot を選べます。
