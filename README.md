# dot

dot は、画像や動画を投稿の本文・作者情報とともに保存し、後から探せる個人用メディアライブラリです。Windows アプリと Chrome 拡張機能を組み合わせて使います。

[公式サイト](https://apricot-cake.github.io/dot/)

## 主な機能

- X・Bluesky・pixiv の投稿を、画像や動画、本文、作者、反応数とともに保存します。
- ほかの Web サイトの画像・動画を、右クリックから出典 URL とともに保存します。
- 手元の画像・動画を取り込み、タグやフォルダで整理します。
- 保存した投稿を、本文や作者名などから検索します。

ライブラリは端末上のフォルダに保存します。専用アカウントは不要です。外部サービスとの通信や保存データの詳細は、[プライバシーポリシー](docs/PRIVACY.md)を参照してください。

## 必要な環境・インストール

Windows と Chrome が必要です。ストア配布に向けて開発しており、現在はソースから開発環境を準備して起動します。[開発ガイド](docs/CONTRIBUTING.md)に沿って、アプリの起動と拡張機能の登録を行ってください。

配布対象は Windows 11 x64 を予定しています。Microsoft Store と Chrome ウェブストアでの配布方針、対応環境の検証状況は、[配布とストア提出](docs/配布とストア提出.md)にまとめています。

## 使い方

1. アプリを起動し、保存先のライブラリを確認します。
2. Chrome で対応サイトの投稿を開き、拡張機能から保存します。画像・動画だけを保存する場合は、右クリックメニューを使います。
3. アプリで保存した内容を開き、タグを付けたり、本文や作者名で検索したりします。

手元の画像・動画は、アプリのインポートから取り込めます。
