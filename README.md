# dot

dot は、画像や動画を投稿の本文・作者情報とともに保存し、後から探せるメディア管理アプリです。

Windows アプリと Chrome 拡張機能を組み合わせて使います。

## 紹介ページ
https://apricot-cake.github.io/dot

## 主な機能

- X・Bluesky・pixiv の投稿を、画像や動画、本文、作者、反応数とともに保存します。
- ほかの Web サイトの画像・動画を、右クリックから出典 URL とともに保存します。
- 手元の画像・動画を取り込み、タグやフォルダで整理します。
- 保存した投稿を、本文や作者名などから検索します。

## 必要な環境・インストール

現在はソースから開発環境を準備して起動します。ストア配布に向けて開発中です。
